لديك تعديلات غير محفوظة — اضغط «حفظ ونشر» لتطبيقها على الموقع.
كيف تعمل اللوحة؟ (اقرأ مرة واحدة)
  1. كل تغيير (كتابة، تعديل، حذف، تغيير ترتيب أو قسم) يبقى في هذه الصفحة حتى تضغط «حفظ ونشر»، فيُرفع إلى GitHub دفعة واحدة.
  2. بعد الحفظ تُطلق اللوحة workflow اسمه مملكة الأسرار — إعادة بناء القصص يبني الصفحات ويحدّثها خلال 1–3 دقائق. لا تُغلق الصفحة أثناء الرفع فقط.
  3. المقال المكتوب هنا يأخذ علامة «يدوي»، فلا يستطيع البوت حذفه ولا نقله إلى قسم آخر ولا تغيير مكانه.
  4. تحريك أي مقال بالأسهم يثبّته أيضاً («يدوي») لأن نشر البوت يرتّب المقالات الآلية حسب التاريخ فقط.
  5. الصورة: ارفع صورة من جهازك (تُضغط تلقائياً إلى WebP)، أو اتركها فارغة ليَرسم الباني رسماً توضيحياً أصلياً.
  6. «نسيت الرمز» يمسح الإعدادات والمفتاح من هذا المتصفح، فتحتاج إلى مفتاح جديد. الحماية الحقيقية هي المفتاح، وليس الرمز.
  7. كل القصص أعمال إبداعية من تأليف نكسوس، وأي تشابه مع الواقع محض صدفة. التزم بالسلامة العائلية: بلا عنف مصوّر أو دماء أو سبّ أو كراهية، وركن الأطفال أشدّ.

لوحة تحكم مملكة الأسرار

صفحة خاصة بصاحب مملكة الأسرار الشخصية: لا تُفهرس في محركات البحث ولا تُربط من أي صفحة، ولا يمكن فعل أي شيء فيها بدون مفتاح GitHub الخاص بك.

أنشئ مفتاح GitHub Fine-grained مقصوراً على هذا المستودع وحده، بصلاحيات Contents: Read and write + Actions: Read and write، ومدة صلاحية 90 يوماً. يُحفظ المفتاح في متصفحك فقط ولا يُرسل إلا إلى api.github.com. أنشئه من github.com/settings/personal-access-tokens/new.
